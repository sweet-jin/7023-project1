# Project 1 问题定义与数据策略

> 依据：课程 Overview PPT（Concrete MiC Inspection Items，Fig. 1–7）与项目简介
> 目标：为"任务感知双头深度学习框架"建立形式化的问题定义

## 1. 总体问题

给定一个已建成（as-built）MiC 混凝土模块或预制构件的 3D 点云（可选配 2D 图像），自动测量其几何质量指标，并判定是否满足容差要求。输入点云由激光扫描/结构光获取，含噪声、稀疏与遮挡。

**输入**：点云 $P = \{p_i \in \mathbb{R}^3\}_{i=1}^{N}$（可选逐点特征/颜色）
**输出**：
1. 逐点语义/实例分割（部件与表面区域）
2. 每个区域的几何测量量 $\hat{m}_k$（长度、平整度、垂直度等）
3. 任务类型识别（该模块/区域适用哪种检测任务）

## 2. 检测项任务化（对应课程 Fig. 1–7）

将检测项归为 6 个任务类别，每个任务由 Head 2 中对应的测量子头处理：

| 任务 ID | 任务名 | 对应课程图 | 检测项 | 测量量定义 |
|---------|--------|-----------|--------|-----------|
| T1 | 尺寸测量 | Fig. 1 | Length / Height / Width / Clear height / Diagonal | 平行表面间距离（净空高度=地面到天花）、PCA/最小包围盒三轴尺寸、对角点距离 |
| T2 | 平整度测量 | Fig. 2 | Surface evenness / Surface flatness | 点云到拟合参考平面的最大偏差（evenness 用 2m 直尺规则，flatness 用整体平面拟合残差 std/max） |
| T3 | 垂直度测量 | Fig. 1, 4 | Perpendicularity / External corner / Internal corner | 表面法向量与参考轴（重力轴或相邻面）的夹角/偏移 |
| T4 | 门窗洞口测量 | Fig. 3 | Door size / Window size | 洞口矩形包围盒的宽×高，以及洞口边缘直线度 |
| T5 | 孔洞测量 | Fig. 6-1/6-2 | Through hole / Equipment holes / Enlarged detail | 圆形孔的直径与位置；异形孔的等效直径/尺寸 |
| T6 | 预埋件测量 | Fig. 7 | Embedded parts（线管/水管/钢管/线耳/驱动管） | 预埋件凸出高度、位置偏差、方向角 |

任务标签说明：每个模块样本带一个主任务（单任务设定，便于训练与评测）；多任务扩展通过任务路由的软分配（soft routing）实现。

## 3. 容差与合规判定

- 课程 PPT 未给出具体容差数值；实现时以**配置项**形式定义（`configs/default.yaml` 中 `tolerances`），默认参考香港 MiC 工程惯例（如尺寸 ±5 mm、平整度 3 mm/2m、垂直度 3 mm/1m），**最终以 CI3LAB 数据集标注为准**。
- 判定输出：每个测量量给出 `measured / tolerance / pass`。

## 4. 评价指标

- 测量精度：MAE、RMSE（mm 级），按任务分项统计
- 分割精度：mIoU（语义）、mAP@50（实例，若采用实例头）
- 任务识别：分类准确率
- 合规率：pass 比例与真值一致性（错判为风险项）

     - 模块类型：客厅/卧室、厨房、卫生间及其组合（对应课程 Fig. 1–5 的六类）
